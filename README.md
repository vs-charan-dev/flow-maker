# AI Flow Companion

A lightweight productivity web app that converts long, monotonous work sessions into short, varied, game-like AI missions.

## Prerequisites

- Node.js 18.18+ or 20+
- npm (or compatible package manager)

## Installation

```bash
npm install
```

## Development

To start the local development server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

To build the application for production:

```bash
npm run build
```

To run the production build:

```bash
npm run start
```

## Running Tests & Linting

```bash
npm test
npm run lint
```

## Configuration Note

No API keys or environment variables are required in configuration files or `.env`. You configure your OpenRouter API key and preferred model ID directly in the application GUI via the Settings modal.
